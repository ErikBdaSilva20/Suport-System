# Créditos e proveniência

Este projeto começou como um template/boilerplate remixado da plataforma
[viverdeia.ai](https://viverdeia.ai/) e foi adaptado às necessidades específicas
da **MasIA** (fluxo de help desk com papéis `admin`/`manager`/`rep`, integração
com WhatsApp, gateway multi-tenant, etc.).

- **Base/template original:** [viverdeia.ai](https://viverdeia.ai/)
- **Adaptação:** MasIA
- **Licença:** [MIT](./LICENSE) — aplicável ao código deste repositório.

Nenhuma reivindicação de titularidade é feita sobre a plataforma viverdeia.ai
em si; este arquivo serve apenas para deixar claro, de forma transparente, de
onde o template-base deste projeto veio antes das modificações da MasIA.
